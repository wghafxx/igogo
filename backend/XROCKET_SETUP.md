# Подключение xRocket

В Railway → сервис `bloxgrade` → Variables добавьте:

| Переменная | Значение |
| --- | --- |
| `XROCKET_API_TOKEN` | API Token приложения xRocket |
| `XROCKET_WEBHOOK_SECRET` | Отдельный Webhook Token того же приложения |
| `PUBLIC_APP_URL` | `https://bloxgrade.up.railway.app` (или ваш актуальный домен, без `/` в конце) |

`XROCKET_API_BASE_URL` необязателен: по умолчанию `https://pay.api.xrocket.exchange`.
Для тестовой сети: `https://pay.api.testnet.xrocket.exchange` и ключи тестового приложения.
Ключи задаются только на backend, без префикса `REACT_APP_`. В репозитории ключей нет.
Без обоих ключей приложение продолжает работать, создание счетов xRocket отключено.

В @xRocket → Pay API → ваше приложение → Settings → API Version выберите **Current**.
Адрес вебхука для текущего сайта:

`https://bloxgrade.up.railway.app/api/payments/xrocket/webhook`

Код также передаёт этот адрес в `callback.callbackUrl` каждого счёта, используя `PUBLIC_APP_URL`.
После изменения переменных примените изменения через **Deploy** и дождитесь успешного deployment. В сервисе должен быть включён деплой ветки `main` из `wghafxx/igogo`. Сборка использует существующий Dockerfile; отдельные сервисы для xRocket не нужны.

Webhook Token в Railway должен в точности совпадать с Webhook Token приложения xRocket. Если в настройках приложения есть поле Webhook URL, укажите адрес выше. Отдельно разрешать вывод средств для этой интеграции не требуется.

## Условия оплаты

- От 35 ₽ до 1 000 000 ₽; тариф 1 RAP = 0,50 ₽.
- Пользователь вводит рубли. Сервер получает курс через xRocket `GET /api/v1/rates?base=RUB`, фиксирует сумму выбранной криптовалюты и создаёт счёт с одинаковыми `priceCurrency`, `payoutCurrency` и `payCurrencies[0]`. Повтор запроса использует уже сохранённую сумму и ID.
- `isFeePaidByUser: true`: комиссия xRocket оплачивается дополнительно и отображается у провайдера. Не используется фиксированный процент из изображения-примера.
- Комиссия сайта — 0%. 35 ₽ дают 70 RAP, с `PELMEN` (+10%) — 77 RAP. Зачисление целиком на баланс.
- Промокод и сумма фиксируются при создании счёта. Комиссия 20% и выдача скинов продолжают действовать только для пополнения скинами.
- Время жизни счёта — час (`expiresIn: 3600`). Проверено по фактическим `createdAt` и `expiresAt` реального API. На 13.09.2026 описание миллисекунд в OpenAPI не соответствует поведению production.
- Реальный API пока отклоняет счета `rub → crypto` с `not_implemented`, несмотря на поля в OpenAPI. Поэтому рубли конвертируются сервером до создания счёта. USDT/USDC используют 6 знаков после запятой, BTC — 8; точная сумма проверяется повторно перед зачислением.

## Что проверить после подключения

1. `/api/payments/xrocket/info` возвращает `enabled: true`.
2. В «Пополнить → Рубли → xRocket» кнопка «Оплатить в Telegram» создаёт счёт от 35 ₽ и сразу открывает его ссылку. В Telegram откройте бота и подтвердите оплату. Новые переменные для этого исправления не нужны.
3. В xRocket видны сумма, выбранная валюта и комиссия. После оплаты счёт появляется зачисленным в профиле и в админке → «Платежи xRocket».
4. Повторная проверка оплаты сохраняет баланс. Повтор вебхука также не добавляет деньги снова.
5. Закрытие окна/браузера не мешает зачислению: webhook обрабатывается сервером, а фоновая сверка восстанавливает пропущенные уведомления.

Возврат на `?payment=xrocket` сам по себе не подтверждает оплату. Сервер проверяет подпись webhook (`v1`, HMAC-SHA256, допуск 5 минут), получает счёт по API и сверяет его ID, зафиксированную сумму криптовалюты, валюту и статус `paid`. Старые счета в рублях проверяются по исходной рублёвой сумме. Частичная оплата не зачисляется как полная.
Автотесты используют изолированную базу. Дополнительно создание и чтение неоплаченных счетов USDT и BTC проверены на production API, включая точность суммы, ссылку Telegram и срок действия; диагностические счета отменены. Перевод денег и реальное зачисление через провайдера не выполнялись.

Документация: [Pay API](https://docs.xrocket.exchange/api/pay/pay-api-overview), [актуальный OpenAPI](https://pay.api.xrocket.exchange/api/docs/), [подпись webhook](https://docs.xrocket.exchange/api/pay/webhooks/signature).
