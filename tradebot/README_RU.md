# Инструкция на русском

Актуальная полная инструкция находится в [README.md](README.md).

Порядок: установить зависимости → `python calibrate.py` → заполнить точные usernames в `config.yaml` → `python bot.py --check` → `python bot.py`. При обновлении прежней клиентской калибровки достаточно `python calibrate.py --names-only`.

Остановка: **F8 / Ctrl+C**. Диагностика без кликов: `python debug_vision.py`. В списке читаются верхнее имя и нижний @username; в трейде сверяется сохранённое верхнее имя. Разрешение — только по нижнему @username.

Программа нажимает кнопки в реальной игре. Сайта и зачислений нет. Закрытие окна без нового уведомления успеха не считается принятым обменом. Совместимость с настоящим Roblox необходимо подтвердить на Windows; офлайн-тесты её не доказывают.
